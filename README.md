# BMI Calculator Using Python

A Python-based BMI Calculator with a graphical user interface built using Tkinter. The application calculates Body Mass Index (BMI), classifies the result into standard health categories, validates user input, and provides BMI visualization using Matplotlib.

## Features

- Calculate BMI using weight and height
- BMI displayed to 2 decimal places
- BMI classification:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Input validation
- User-friendly Tkinter GUI
- Color-coded BMI results
- BMI trend visualization using Matplotlib
- Error handling for invalid input

## Technologies Used

- Python
- Tkinter
- Matplotlib
- SQLite3
- Git
- GitHub
